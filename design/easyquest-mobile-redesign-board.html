EasyQuest: профессиональные mobile-first направления

Пять продуктовых концепций для текущей React Native/Expo codebase. Все экраны используют существующую логику: компактная карточка баллов, уровень без персонажей, специальные progress bars, карточки задач с левым цветовым блоком и мобильная нижняя навигация.

Источник паттернов Основано на `child/dashboard`, `tasks`, `rewards`, `balance`, `achievements`, `growth-missions`, `BottomActionBar`, `QuestIcons` и текущем `RocketProgressBar`. В макетах нет внешних emoji, lucide, новых персонажей или generic progress.

Classic EasyQuest

Palette tokens
#1647B7 · #10233F · #D8FF3E · #F7B721 · #EDF5FF
Роли цветовBlue = CTA и active nav; graphite = hero depth; lime = короткие success/active акценты; gold = баллы и награды.
ПиратТолько карточка баллов, success/empty states. Не использовать в task/reward rows.
СвинкаRunner только в progress главной цели. `piggy-bank-mascot` только nav/icon label миссий.
Progress barGoal: runner+glow. Level/reward/wish/achievement: compact/no runner/no glow.
StatesAvailable = blue CTA; pending = warm badge; done = green; rejected = orange/red; nav active только label color.
