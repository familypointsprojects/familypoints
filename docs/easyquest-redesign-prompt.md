# EasyQuest Redesign Prompt

Редизайн приложения EasyQuest по мотивам `design/easyquest-effects-concept-v2.html` без изменения бизнес-логики.

Сохранить все маршруты, провайдеры состояния, авторизацию, формы, Supabase/local services, обработчики кнопок, расчеты баланса, наград, заданий, миссий роста и проверки ролей. Работать через существующие shared UI-компоненты, чтобы визуальные изменения применились ко всем родительским и детским сценариям.

Визуальное направление:

- Светлая игровая среда: ice/sky background `#EDF5FF`, белые поверхности, мягкие синие бордеры, чистая типографика без декоративного маркетингового экрана.
- Главный брендовый слой: глубокий quest blue `#0B2B70` / `#1647B7`, акценты cyan, mint, lime, gold, orange.
- Карточки должны ощущаться как мобильный game UI: плотные, читаемые, с мягкой тенью, четкой иерархией и без вложенных декоративных карточек.
- Баланс, очки, награды и XP-прогресс сделать главными визуальными сигналами: монетные бейджи, выразительный progress, яркие статусы.
- Использовать существующие EasyQuest assets: логотипы, маскот/ракета, quest icons. Не заменять функциональные иконки случайным декором.
- Нижняя навигация остается в том же составе и с теми же переходами, но получает более чистый glass/ice вид и активный синий акцент.
- Все тексты должны помещаться на мобильных экранах, без перекрытий. Не менять ключи i18n и не удалять русско-английскую локализацию.
