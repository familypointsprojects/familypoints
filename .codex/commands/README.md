# EasyQuest Codex Commands

These command prompts are reusable shortcuts for the local designer skills.

Use them by asking Codex to run the command name with a target screen, flow, or design task. The app's quick slash menu indexes commands from installed plugins; the matching `easyquest-designers` plugin contains the same commands for quick access.

## Commands

- `/product-design <flow or screen>` - use `product-designer` for UX flows, screen structure, states, and CTA copy.
- `/ui-design <screen or component>` - use `ui-designer` for visual direction, layout, tokens, icons, and interaction states.
- `/ux-review <screen or flow>` - use `ux-reviewer` to find UX issues, missing states, unclear CTAs, and MVP scope creep.
- `/design-system <component area>` - use `design-system` to plan tokens and reusable React Native component APIs.
- `/figma-prompt <screen set or brief>` - use `figma-prompt-designer` to create Figma AI or Recraft prompts.

## Examples

```text
/product-design child task submission flow
```

```text
/ui-design child dashboard
```

```text
/ux-review parent rewards screen
```

```text
/design-system task cards and reward cards
```

```text
/figma-prompt all MVP parent and child screens on one Figma page
```
