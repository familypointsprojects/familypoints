# /ui-design

Use `ui-designer` for this EasyQuest task:

`$ARGUMENTS`

Create a warm, modern, adventure/quest-inspired mobile UI direction. Parent screens should be calm and clear; child screens can be more playful and motivating without becoming childish.

Return the result in this format:

- Visual concept
- Layout
- Color tokens
- Typography
- Components
- Icons/illustrations
- Interaction states
- React Native implementation hints
