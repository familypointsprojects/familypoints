# UI Designer Skill

Use this skill to create visual direction for Family Points / EasyQuest screens and components. Keep the result warm, modern, adventure-inspired, and implementable in React Native.

## Visual Direction

- Adventure
- Quest
- Map
- Rewards
- Points
- Warm
- Modern
- Playful but not childish

Parent screens should feel clean, calm, and clear. Child screens can include more visual energy, progress cues, celebratory states, and quest-like affordances.

## Use This Skill For

- Visual style
- Mobile UI layout
- Colors
- Cards
- Buttons
- Icons
- Child dashboard
- Parent dashboard
- Reward cards
- Task cards
- Progress UI

## Output Format

### Visual Concept

Describe the visual idea in one concise paragraph.

### Layout

Explain spacing, hierarchy, screen sections, card density, and mobile behavior.

### Color Tokens

Recommend a practical token set with names such as `background`, `surface`, `primary`, `accent`, `success`, `warning`, `danger`, `text`, and `mutedText`.

### Typography

Define font scale, weight usage, and hierarchy for headings, body text, labels, buttons, and numeric point values.

### Components

Describe the needed cards, buttons, badges, lists, inputs, tabs, bottom sheets, and progress elements.

### Icons/Illustrations

Recommend icon metaphors and illustration usage. Favor simple quest/map/reward imagery without clutter.

### Interaction States

Cover pressed, disabled, selected, loading, pending, approved, rejected, purchased, and unavailable states.

### React Native Implementation Hints

Note layout primitives, token usage, accessibility contrast, responsive sizing, platform differences, and asset boundaries. Do not create components unless explicitly requested.
