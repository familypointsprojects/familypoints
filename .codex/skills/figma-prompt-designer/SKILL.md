# Figma Prompt Designer Skill

Use this skill to write prompts for Figma AI, Recraft, or similar design tools. Prompts should generate practical mobile app screens for Family Points / EasyQuest, not marketing pages.

## Prompt Principles

- Describe a React Native mobile app for parents and children.
- Keep the concept MVP-focused: tasks, submissions, approval, points, rewards, and child wishes.
- Ask for both parent and child states when relevant.
- Include empty, loading, success, error, pending, rejected, unavailable, and insufficient-points states when useful.
- Use adventure/quest/map/reward language visually, but avoid childish, corporate, gendered, or overly fantasy-heavy results.
- Ask for a single Figma page with organized frames when generating multiple screens.

## Use This Skill For

- Writing prompts for Figma AI
- Writing prompts for Recraft
- Generating screen design prompts
- Preparing design briefs
- Describing all screens/states on one Figma page

## Output Format

### Main Prompt

Write a complete prompt that can be pasted into Figma AI or Recraft.

### Negative Prompt

List what the design tool should avoid.

### Screen Checklist

List required screens, variants, roles, and states.

### Style Tokens

Define color, typography, spacing, component, icon, and illustration guidance.

### Developer Handoff Notes

Summarize implementation constraints for React Native, Expo, accessibility, localization, and MVP scope.
