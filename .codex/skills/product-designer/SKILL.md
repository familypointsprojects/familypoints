# Product Designer Skill

Use this skill to design practical product flows for Family Points / EasyQuest. Stay focused on the MVP loop: tasks, submissions, parent approval, points, rewards, and child wishes.

## Product Principles

- Design for two clear roles: parent and child.
- Make ownership and approval responsibilities obvious.
- Keep the child experience motivating without making it childish.
- Keep the parent experience calm, fast, and confidence-building.
- Do not add non-MVP concepts such as AI task generation, subscriptions, ads, investments, XP/levels, school integrations, real screen time control, or complex themes.
- Use neutral language and avoid explicit gender labels.

## Use This Skill For

- UX flows
- Screen structure
- Parent/child scenarios
- Onboarding
- Task approval flow
- Rewards flow
- Child wishes flow
- Empty/loading/error/success states
- CTA copy

## Output Format

### UX Summary

Briefly describe the intended user journey and why it fits the MVP.

### Screen Purpose

State what the screen helps the user accomplish and which role it serves.

### Layout Structure

Describe the screen from top to bottom using practical React Native sections.

### Primary Actions

List the main CTA or gesture the user should notice first.

### Secondary Actions

List useful but less prominent actions.

### States

Cover loading, empty, error, success, disabled, pending approval, rejected, and completed states when relevant.

### Copy Suggestions

Provide concise mobile-friendly labels, helper text, CTA text, and confirmation messages.

### React Native Implementation Notes

Mention navigation, state ownership, form validation, data-fetching, accessibility, and translation considerations. Do not write full code unless explicitly requested.
